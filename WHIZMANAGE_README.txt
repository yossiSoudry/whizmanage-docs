== Description ==

🎯 **WhizManage - The Ultimate WooCommerce Management Suite**

Manage your entire WooCommerce store smarter, faster, and with zero frustration.

WhizManage is a powerful admin toolkit that replaces dozens of slow and repetitive product screens with one modern, high-performance dashboard — built for store owners, agencies, and developers who want efficiency.

= 🚀 Why WhizManage? =

✔ Manage products, variations, taxonomies, coupons, and more — in seconds, not hours
✔ A clean, fast, React-based UI that feels native to WordPress
✔ Works flawlessly with RTL (Hebrew), multilingual stores, and large catalogs
✔ Designed to grow: from small stores to 100,000+ products

= 🆓 Free Version Features =

**🧾 Advanced Product Management**

Spreadsheet-style interface for editing simple and variable products with instant updates.

* ⚡ Quick Table Editing — Manage all your products quickly and efficiently, just like in a spreadsheet
* ➕ Easy Product Creation — Intuitive form for creating new products
* 🔧 Customizable Columns — Show, hide, resize and reorder columns to fit your workflow
* 🔍 Smart Filtering — Find products instantly with powerful search and filter options

**💡 Variation Control**

Manage prices, stock, attributes, and images for all variations directly from a single panel.

* 🏷️ Product & Global Attributes — Support for both product-specific and store-wide attributes
* ✨ Any Mode — Simplified variation management when options share the same price/stock
* 🔄 Bulk Generation — Automatically create all possible variation combinations
* 👁️ Visual Management — Clear, intuitive interface for complex variation structures

**🎟️ Advanced Coupon Manager**

A powerful, spreadsheet-style interface for complete coupon management.

* 📊 Spreadsheet-Style Interface — View and edit all coupons in one organized table
* ✏️ Inline Quick Editing — Edit coupon details directly in the table without popups
* 📋 One-Click Duplication — Duplicate existing coupons instantly
* 📦 Bulk Operations — Update multiple coupons simultaneously
* 🔍 Smart Search & Filters — Find coupons by code, discount type, or status
* 📅 Expiry Management — Easily track and manage coupon expiration dates
* 📈 Usage Statistics — View usage counts and limits at a glance
* 🎯 Discount Types — Percentage, fixed cart, fixed product discounts
* 🛒 Cart Conditions — Minimum spend, maximum spend, product restrictions

**👥 Customer Management**

Streamlined customer overview and management tools.

* 📋 Customer Directory — View all customers in a clean, sortable table
* 🔍 Quick Search — Find customers by name, email, or order history
* 📊 Purchase History — See customer order summary at a glance
* 📧 Contact Information — Easy access to customer details
* 🏷️ Customer Segments — Filter by purchase behavior and history

**📦 Orders Management**

Efficient order processing with smart bulk actions.

* 📊 Order Dashboard — Overview of all orders in spreadsheet format
* 🔄 Status Updates — Quick order status changes
* 📦 Bulk Processing — Handle multiple orders at once
* 🔍 Advanced Filters — Filter by status, date, customer, or products
* 📈 Order Analytics — Track sales performance and trends
* 🖨️ Quick Actions — Print invoices, packing slips with one click

**⚙️ Clean & Fast UI**

A modern experience optimized for performance, usability, and RTL layouts.

* 🌓 Light & Dark Themes — Choose your preferred interface theme or sync with system settings
* 📱 Responsive Design — Works great on any screen size
* ↔️ RTL Support — Full right-to-left layout support for Hebrew, Arabic, and more

== Installation ==

1. Upload the plugin to `/wp-content/plugins/whizmanage` or install via the WP plugin installer
2. Activate WhizManage from the Plugins menu
3. Go to **WhizManage → Products Editor** to start managing your store

= System Requirements =

* ✅ Updated WordPress version
* ✅ Updated WooCommerce version
* ✅ Modern browser (Chrome, Firefox, Edge, Safari)
* ✅ Stable internet connection
